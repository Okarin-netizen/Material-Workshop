# マテリアル工房 目的と要求

このアプリを直すときは、まずこの文書の「目的」と「成功の目安」に照らして、その変更が要るかを決めます。
変更したら「要求一覧」の状態と「変更の記録」を更新します。

- 最終更新：2026-11-23（アプリ v1.4.1 の時点）
- 決める人：技術科　岡田

## 1. 目的

| 項目 | 内容 |
| --- | --- |
| 教科・単元 | 中学1年 技術分野「材料と加工の技術」 |
| 使う場面 | 授業1コマ（50分）の中で使う |
| 成功の目安 | 生徒が、使用目的と条件に合った材料を、理由付きで選べるようになる |
| 合わせる教科書 | 東京書籍（版は要確認）。画面に出る「教科書 p.○」はこの教科書のページ |

### 成功の確かめ方

- まとめ画面の「この設計を選んだ理由」に、材料の性質の言葉（強さ・軽さ・さびにくさ・加工のしやすさなど）を使った理由が書けているかを、先生が読んで確かめる。
- 星や得点は「ゲーム用の目安」で、成功の目安そのものではない。

## 2. 関係者

| 人 | かかわり方 |
| --- | --- |
| 生徒（中学1年） | 使う。理由を書き、まとめを印刷して出す |
| 技術科の先生 | 授業で使わせる。依頼を開く・記録を消す。理由を読んで確かめる。内容の正しさを確かめる |
| 学校の情報担当 | 端末とネットワークの管理（公開ページを開けるか） |

## 3. 要求一覧

状態：候補 → 承認 → 実装済み → 検証済み（ほかに 見送り・保留）

| ID | 要求 | 種別 | 優先度 | 状態 | 確かめ方 |
| --- | --- | --- | --- | --- | --- |
| G-01 | 生徒が、使用目的と条件に合わせて材料・加工・丈夫にする工夫を選び、理由を書ける | 学習 | Must | 承認 | まとめの理由欄を先生が読む |
| G-02 | 50分の授業の中で、決めた数の依頼（数は要確認）を終えられる | 学習・非機能 | Must | 候補 | 生徒に試してもらい、時間を測る |
| G-03 | 理由を書かずに先へ進む生徒を減らす（書く手助けがある） | 学習 | Should | 候補 | 生徒に試してもらい、空欄の数を数える |
| L-01 | 画面の数値・説明が、教科書の内容と食いちがわない | 学習 | Must | 候補 | 先生が教科書と照らし、日付を記録する |
| L-02 | 画面の教科書ページが、東京書籍の使っている版に合っている | 学習 | Must | 候補 | 版を決めて照合する |

## 4. 保存するデータ

| データ | どこに | 誰が見られる | どう消す |
| --- | --- | --- | --- |
| 進み具合・星・最高の設計 | 端末のブラウザ（localStorage） | その端末を使う人 | 先生用「最初からやり直す」 |
| 選んだ理由（80字）・ふり返り（300字） | 同上 | 同上 | 同上（授業での運用は要確認） |
| 年・組・番・名前 | まとめ画面の入力欄だけ | 入力中の人 | 保存しない |

## 5. まだ決まっていないこと

1. 50分で何依頼まで進める前提か（全8依頼か、見習いの3依頼くらいか）
2. 東京書籍の教科書の版
3. 端末は1人1台か共有か。共有なら授業後に記録を消すか
4. まとめの印刷や星を評価に使うか
5. 公開範囲（自分のクラスだけか、他校にも）とライセンス
